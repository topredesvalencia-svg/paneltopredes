# Panel Top Redes Valencia

Página de entrada con enlaces a las aplicaciones internas.

## Desplegar en Streamlit Cloud
1. Sube esta carpeta a un repositorio de GitHub (`app.py`, `requirements.txt`, `.gitignore`, `README.md`).
2. En share.streamlit.io → **New app** → elige el repositorio y `app.py` como archivo principal.

## Cambiar datos
Edita la lista `APPS` al principio de `app.py` para cambiar títulos, descripciones, URLs o iconos.
